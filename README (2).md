# FRUIT.IO Multiplayer Server

Node.js and Socket.IO backend for FRUIT.IO.

## Requirements
- Node.js
- npm

## Installation

```bash
npm install
```

## Start Server

```bash
npm start
```

## Health Check

After deployment, open `/health` on your server URL.

## Hosting

Designed for deployment as a Render Web Service.

## Important

Configure the frontend CORS origin and any required environment variables before production deployment.
